# LIVE — CVPR 2027 workshop website

Static website for the proposed LIVE workshop on real-time generative worlds and human–AI interaction.

The site is served by GitHub Pages from the root of the main branch. Edit `index.html` for content and `styles.css` for layout. Local assets are in `assets/`.

Workshop dates and submission arrangements remain tentative as stated on the website. Image and font sources are recorded in `credits.html` and the included font license files.
